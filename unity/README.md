# In-world models (Unity build)

This folder holds custom 3D models for the mods, ready for Foxy Voxel's Unity modding project ([FoxyVoxel/going-medieval-modding](https://github.com/FoxyVoxel/going-medieval-modding), MIT). The game loads custom meshes and textures only as Unity Addressables, so they need one build in Unity. The mods work without it: until the Addressables exist, the buildings keep their vanilla models.

| Mod | Model | Replaces |
|---|---|---|
| Cold | `Cold/Mesh/phrontisteries_cold_shelf.obj`: wooden shelf with frosted top, icy edges and icicles. Boards line up with the game's pile slots, so stored items sit on them. | the vanilla shelf model on the Cold Shelf |
| Fish_Farming | `Fish_Farming/Mesh/phrontisteries_fish_farm.obj`: staved tub of water with a leaping fish, a feed sack and a bucket | the saltpeter-pit model on the Fish Farm |

Each model has a palette texture in `Texture/` (`<mesh>_palette.png`). All of it is generated by `tools/art/make_art.py` (models in `tools/art/models.py`).

The Cold Floor needs no build: it is tinted through the floor shader's own colour parameters.

## Build steps (once per change to a model)

1. Install **Unity 2022.3.46f1** through Unity Hub, with **Windows Build Support**.
2. Clone `https://github.com/FoxyVoxel/going-medieval-modding.git` and open it from Unity Hub.
3. Copy `unity/Cold` and `unity/Fish_Farming` from this repo into the project's `Assets/Mods/`. The folder names must match the mod folder names.
4. In Unity, select each `Texture/*_palette.png` and set **Filter Mode = Point**, **Generate Mip Maps = off**, **Compression = None**, then Apply. This keeps the flat colours crisp.
5. Open **Going Medieval > Addressable Builder**. Select **Cold**, click **Create Addressables**, then **Build**. Do the same for **Fish_Farming**.
6. Copy the contents of `Assets/Mods/<Mod>/Exported/` into this repo's `recipes/<Mod>/AddressableAssets/`.
7. Rebuild the mod: `.\MakeMod.ps1 -ModName Cold` (or `-All`). MakeMod sees the catalog, copies it to `Data\AddressableAssets`, and switches the building to the custom model (`Set-ModelMesh` in the recipe).
8. Test in game, then commit `recipes/<Mod>/AddressableAssets` and the rebuilt mod.

## Notes

- The models are `.obj`. Unity imports OBJ directly. If you prefer FBX, as Foxy Voxel's guide suggests, open the `.obj` in Blender and export FBX with the same name (1 unit = 1 m, Y up).
- Units are metres with Y up. The origin is the centre of the building's tile at floor level.
- Asset names: Foxy Voxel's builder uses each file name, without extension, as its address. The recipes reference `phrontisteries_cold_shelf`, `phrontisteries_cold_shelf_palette`, `phrontisteries_fish_farm` and `phrontisteries_fish_farm_palette`, so keep those names.
- Untested so far: whether the game's shader likes the palette texture with empty reflection and emission slots, and the exact pivot the game expects. Check both on the first in-game test.
