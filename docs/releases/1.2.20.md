Mods for **Going Medieval 1.2.20**. Download `GoingMedievalMods-1.2.20.zip` below (or the source zip, under `Mods/`). Copy a mod's folder into `Documents\Foxy Voxel\Going Medieval\Mods\` and enable it in the game's Mods menu (or subscribe on the Steam Workshop).

### Changes since 1.2.17
- **Cold:**
  - The Cold Shelf now uses the game's shelf model with a subtle frost-blue texture.
  - New **Cold Floors** for all 10 floor materials (wood, wicker, limestone, limestone block, clay brick, decorative stone, clay and marble, metal grate and wicker mesh). Each has frosted bricks, tiles or planks in a repeating pattern, and they have their own build-menu group.
- **New:** Brokerastered and More Creation Points, plus a remade Heavy Crossbow Sniper.
- **Removed: Urgent Haul – Bodies.** Any mod that changes `GOAP/Job.json` hangs the game's loading screen on 1.2.17 and 1.2.20. This is a game bug, reported to Foxy Voxel. If your game is stuck loading, end it in Task Manager and disable the mod in `AppData\LocalLow\Foxy Voxel\Going Medieval\global.config`.
- **Art:**
  - New build-menu icons for the Cold Shelf, the Cold Floors and Mushroom Cropfield.
  - New preview images for every mod.
  - Descriptions in 12 languages.
- **Fixed:** mods missing from the in-game menu, and the pike yield.

All mods are version `1.0.2.20`. Their game data was checked against 1.2.20 and needed no changes.

### Tooling
- Every mod is built from a recipe by `MakeMod.ps1`.
- The Cold textures are built with Foxy Voxel's Unity modding project (steps in `unity/README.md`).
